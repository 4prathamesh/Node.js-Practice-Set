# E-commerce Async Patterns Demo

This project demonstrates:

- Callback-based async handling
- Promise-based handling
- Async/Await (modern approach)

## APIs

- /api/v1/callback-order
- /api/v1/promise-order
- /api/v1/async-order

## Tech Stack

- Node.js
- Express.js

## Purpose

To understand different async patterns in real-world e-commerce flow.
